# null
- 메모리는 수로 저장
- 포인터도 수인데 주소(수) 저장 -> null(매크로) -> nullptr (최근 트렌드)
null이 뭘까?
- null reference exception / out of bound(range) / stack overflow 이런 오류가 있음
- null 에 접근하거나 뭐해서 나는 에러이다.
- 변수 만나면 0으로 초기화함. 값 세팅을 0으로
주소가 0번지가 왜 예외일까?
- null에 접근하면 왜 오류일까?
- 주소에서 0번지는 실제로 있는 주소이지만, 운영체제가 있을 가능성이 높다.
- 정확히는 모름
- device NULL 0
- nullptr 은 0번지를 내포하고있다.

정적함수는 this가 안된다.
왜? static 적용 범위는 메모리, 데이터영역에 들어간다.
static 함수는 데이터영역에서만 접근 가능
this는 객체마다 다름, 힙이나 스택에 있음, 데이터 영역에 있지않음
static 영역에서 하려면 static이 붙은 변수만 가능
왜? (구조적으로)
초기화시점이 다름
변수 다룰 때 static 변수가 초기화되는(메모리 잡히는) 시점이 다르다.
프로그램 초기화 할때, static은 초반에 잡힘,
객체 생성될 때 잡힘
